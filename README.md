# Crack the Code

Complete ten-week Year 7–8 Technology course website for control systems, Arduino coding and the ThinkerShield final alarm challenge.

## Student experience

- course home plus ten dedicated module pages
- three source-bound theory sections per module
- 300 checked questions and 30 guided written responses
- 30 click-to-play video learning cards and 30 open-larger diagrams
- ten downloadable eight-slide module presentations
- ten autosaving project activity studios covering all sixteen authorised practical tasks
- consolidated folio with device-local autosave, backup, restore and print
- dedicated assessment and teacher-resource pages

## Storage boundary

Browser progress is device-local practice only. It does not upload to Google Drive or submit to Google Classroom. Current formal arrangements remain Teacher to confirm.
