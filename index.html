The challenge

One final alarm. Every lesson earns its place.

Each module teaches three precise ideas, checks your understanding, guides one written response and sends you into practical work. The final system must use the fixed ThinkerShield inputs and outputs, with outputs changing according to input data.

Course pathway

Ten modules from first signal to final evaluation

Open all project activities →
  1. 01
    Systems that sense and respond

    Input, processing, output and the fixed hardware map.

  2. 02
    Make light obey the code

    Sketch structure, digital states and timing.

  3. 03
    Plan the logic before coding

    Algorithms, pseudocode, flowcharts and branching.

  4. 04
    Read changing data

    Analogue values, mapping and calibration.

  5. 05
    Sense the light

    LDR readings, thresholds and response loops.

  6. 06
    Make the code choose

    Button input, if/else and stored state.

  7. 07
    Turn numbers into sound

    Buzzer frequency, mapped pitch and sequences.

  8. 08
    Combine parts into systems

    Arrays, iteration, functions and subsystems.

  9. 09
    Design the final alarm

    Criteria, system planning, code and test cases.

  10. 10
    Debug, improve and explain

    Systematic debugging, evaluation and backup.

Current NSW syllabus

Designed for Technology 7–8 (2023), implemented from 2026.

The strongest alignment is with TE4-DIG-02: using data and digital systems to code, design and produce projects. The unit also develops safe technology use, planning, systems thinking, communication and evaluation. See Teacher resources for the source-bound mapping.
