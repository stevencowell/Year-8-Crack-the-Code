# Upgrade release definition

This build was benchmarked against The Riv Burger course family and upgraded as a complete system rather than a reskin. Release requires all ten modules, 30 theory sections, 300 checks, 30 guided responses, ten activities, folio, assessment, teacher resources, presentations, visual teaching, video fallbacks, print views and device-local persistence to work together.

The earlier Crack the Code single-page prototype remains useful as source evidence but is not the release architecture.
